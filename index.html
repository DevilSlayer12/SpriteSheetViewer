How it works

  1. Open a sheet (or drag it in). Grids and loose sprites are both found automatically. If something is off, change the Slicing settings or use the Box tool to cut frames by hand.
  2. View any frame by clicking it on the sheet or in the Frames list, then ⤓ PNG downloads it.
  3. Build animations: double-click frames to add them, drag steps in the timeline to reorder, and use Step properties to hold, move, scale, rotate, flip, fade and tween.
  4. Draw: press ✎ Draw to edit pixels on any frame. Use Copy frame to make a new frame from the current one, or New canvas to animate from nothing.
  5. Export GIFs, PNG strips, sprite sheets with JSON, frame ZIPs or video. Save project keeps everything for later.
